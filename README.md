# Computer Fundamentals Lab Practicals

Repository for Computer Fundamentals / IT Lab practicals (Labs 1–12), prepared in practical-record format.

Each lab folder includes:
- **Aim**
- **Procedure**
- **Code / commands / formulas** (where applicable)
- **Expected output**
- **Conclusion**

## Labs included
1. Labs 1–2: CLI commands and file management
2. Lab 3: System configuration and networking commands
3. Lab 4: Professional document in LibreOffice Writer
4. Lab 5: Mail Merge invitation letters in LibreOffice Writer
5. Lab 6: Student marksheet in LibreOffice Calc
6. Lab 7: Attendance spreadsheet in Calc
7. Lab 8: Salary and inventory spreadsheets in Calc
8. Labs 9–10: Educational presentation in LibreOffice Impress
9. Labs 11–12: Algorithms and pseudocode

## How to use
1. Open a lab folder.
2. Read its `README.md`.
3. Run the commands/scripts only in a test folder or use the sample files.
4. For LibreOffice practicals, follow the procedure and save your own `.odt`, `.ods`, or `.odp` work in the relevant folder.
5. Replace expected output with your own screenshot/output if your instructor requires evidence.

## Requirements
- Windows Command Prompt or Linux terminal for Labs 1–3
- LibreOffice Writer, Calc, and Impress for Labs 4–10
- Python 3 is optional for the pseudocode examples in Labs 11–12

## Important
- Commands differ between Windows and Linux; use the section for your operating system.
- Destructive commands such as `rmdir /s` and `rm -r` delete files. Check the path before running them.
- Lab topics 13–14 were not included because that row was cut off in the provided lab-plan image.
