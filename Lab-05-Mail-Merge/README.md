# Lab 5: Personalized Invitation Letters Using Mail Merge

## Aim
To create personalized invitation letters for multiple recipients using Mail Merge in LibreOffice Writer.

## Procedure
1. Open `Recipients.csv` in LibreOffice Calc and review the sample recipient data.
2. Save a copy as `Recipients.ods` if required.
3. Open Writer and draft an invitation letter.
4. Open **Tools → Mail Merge Wizard**.
5. Select the current document and connect the recipient list as the address data source.
6. Insert the relevant fields (for example, FirstName and EventDate) into the letter.
7. Preview several recipients and verify that the fields appear correctly.
8. Finish the wizard and save or print the merged letters.

## Sample invitation text
**Subject: Invitation to the College Event**

Dear [FirstName],

You are cordially invited to our college event on [EventDate]. We look forward to your participation.

Regards,  
Organising Committee

## Expected Output
The same invitation template produces a personalized letter for each row in the recipient list.

## Conclusion
Mail Merge was used to generate personalized letters from one template and a data source.
