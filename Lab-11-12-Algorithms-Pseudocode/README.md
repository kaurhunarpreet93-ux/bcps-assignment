# Labs 11–12: Algorithms and Pseudocode

## Aim
To write algorithms and pseudocode for basic arithmetic and logical problem-solving tasks.

## Procedure
1. Choose a problem and identify its inputs and expected output.
2. Write the solution as a finite sequence of steps.
3. Express the steps in pseudocode.
4. Test with sample values and compare expected and actual results.
5. Optionally run the Python examples in this folder.

## Algorithm 1: Sum of two numbers
1. START
2. INPUT A, B
3. SUM = A + B
4. OUTPUT SUM
5. STOP

## Algorithm 2: Even or odd
1. START
2. INPUT N
3. IF N MOD 2 = 0, OUTPUT "Even"
4. OTHERWISE, OUTPUT "Odd"
5. STOP

## Algorithm 3: Largest of two numbers
1. START
2. INPUT A, B
3. IF A > B, OUTPUT A
4. ELSE IF B > A, OUTPUT B
5. OTHERWISE, OUTPUT "Both are equal"
6. STOP

## Expected Output
For A=8 and B=5, the sum program outputs 13. For N=7, the even/odd program outputs Odd. For equal inputs, the largest-number program reports that both are equal.

## Conclusion
Algorithms and pseudocode were written and tested for arithmetic and logical tasks.
