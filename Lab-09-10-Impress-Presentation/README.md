# Labs 9–10: Educational Presentation in LibreOffice Impress

## Aim
To develop an educational presentation using themes, slide transitions, animations, and multimedia objects.

## Procedure
1. Open LibreOffice Impress and choose a suitable theme or slide design.
2. Create at least five slides on **Introduction to Artificial Intelligence**.
3. Use this outline:
   - Slide 1: Title and presenter
   - Slide 2: Definition of AI
   - Slide 3: Applications of AI
   - Slide 4: Advantages and challenges
   - Slide 5: Conclusion
4. Add relevant images/media and short bullet points.
5. Use consistent fonts, colours, and layouts.
6. Add slide transitions; animate only selected objects to avoid distracting effects.
7. Run the slideshow and check every slide.
8. Save as `Educational_Presentation.odp`.

## Sample slide content
- **AI:** Technology that enables computer systems to perform tasks associated with human intelligence.
- **Applications:** Healthcare, education, transport, language tools, and recommendation systems.
- **Benefits:** Automation, speed, and support for decision-making.
- **Challenges:** Bias, privacy, reliability, and responsible use.

## Expected Output
A five-slide educational presentation with consistent design, selected transitions, animations, and multimedia.

## Conclusion
An educational presentation was created using LibreOffice Impress.
