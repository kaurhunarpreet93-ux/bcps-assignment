# Lab 4: Professional Document in LibreOffice Writer

## Aim
To create and format a professional document using text formatting, a table, header, footer, and page numbering.

## Procedure
1. Open LibreOffice Writer and create a new document.
2. Type a title such as **Computer Fundamentals Practical Record** and add two short paragraphs.
3. Select the title and apply bold, centre alignment, and a larger font size.
4. Choose **Table → Insert Table** and create a table with 3 columns and 4 rows.
5. Enter sample headings such as `S. No.`, `Topic`, and `Description`, followed by sample records.
6. Insert a header and footer using the Insert menu or page-style settings.
7. Insert page numbering in the footer; menu wording may vary by LibreOffice version.
8. Save as `Professional_Document.odt`. Optionally export a PDF.

## Sample table
| S. No. | Topic | Description |
|---|---|---|
| 1 | Writer | Document formatting |
| 2 | Calc | Spreadsheet calculations |
| 3 | Impress | Slide presentation |

## Expected Output
A formatted document containing a title, paragraphs, table, header, footer, and page number.

## Conclusion
A professional document was created using key formatting and page-layout features of LibreOffice Writer.
